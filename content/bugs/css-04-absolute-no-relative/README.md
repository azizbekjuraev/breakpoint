# Badge escapes the card it belongs to

A red "NEW" badge should sit in the top-right corner of a card. It's `position: absolute` with `top: 8px; right: 8px;` — which looks like the right idea. But the badge has flown out to the top-right of the page, not the card.

The numbers are right. The reference point is wrong.
