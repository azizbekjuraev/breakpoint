# Search box that screen readers can't name

The header has a search input next to a placeholder-styled "Search" label. Visually it looks fine. But running a screen reader announces "edit, blank" — no name, no context. The placeholder isn't enough; it disappears the moment the user types, and it isn't a reliable accessible name.

Sighted users can guess what the box is for. Screen-reader users can't.
