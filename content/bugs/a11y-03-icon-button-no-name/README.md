# Icon-only close button announces as "button, blank"

A toast notification has a small × button in the corner to dismiss it. The icon is an SVG path — clean, no text. Visually it reads as "close" to anyone who's used a UI in the last decade.

But a screen reader announces it as just "button" with no name. Voice-control software can't address it ("click close" does nothing). Keyboard users tabbing through hear nothing meaningful.

The button does its job for sighted-mouse users. It's invisible to everyone else.
