# Product card image missing alt text

A product card shows a photo with the product name and price beneath. The image renders fine for sighted users.

For someone using a screen reader, the image is announced by its filename ("photo-2.jpg") — or skipped entirely with no warning that an image was even there. The picture is part of the content; the user has no way to know what it shows.
