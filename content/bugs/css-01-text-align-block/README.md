# Button refuses to sit in the middle

A call-to-action button is supposed to sit dead-center horizontally inside its container. The designer added `text-align: center` to the button itself and… it's still hugging the left edge.

The container has plenty of room. The button looks fine on its own. Something about that `text-align` declaration isn't doing what was intended.
