# Security Policy

## Supported Versions

Currently, we only support the latest version of Breakpoint. Please ensure you are running the most recent version of the code.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us privately.

**Please do not report security vulnerabilities via public GitHub issues.**

To report a vulnerability, please email the author or open a private security advisory on GitHub if available.

We will acknowledge your report within 48 hours and provide a timeline for a fix. We ask that you follow responsible disclosure practices and give us a reasonable amount of time to address the issue before making it public.
